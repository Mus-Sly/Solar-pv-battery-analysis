# Solar PV & Battery Analysis

Python-based data analysis of household solar generation, electricity usage, battery storage, and electricity costs.

## Project Overview

This project analyses hourly electricity generation and usage data to assess the potential impact of adding a battery to an existing solar PV system.

The analysis covers:

- Data quality and completeness checks
- Outlier investigation and correction
- Hourly solar generation and electricity usage
- Electricity purchased without battery storage
- Excess solar electricity available for storage
- Hourly battery charge modelling
- Electricity purchased with battery storage
- Monthly energy analysis
- 20-year financial projections
- Net Present Value (NPV)
- Internal Rate of Return (IRR)

## Tools Used

- Data cleaning and validation
